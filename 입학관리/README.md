# PCMS 입학관리 — 화면 체험판

차세대 PCMS **입학관리** 메뉴의 화면 체험판입니다. 단일 HTML 파일로, 설치·서버 없이 브라우저에서 바로 열립니다.

- 🔗 **체험판 열기**: https://jinilee-hue.github.io/KCMS/입학관리/
- 📐 **디자인 규격**: [디자인가이드.md](디자인가이드.md)

## 사용법

상단 GNB의 **입학관리** 를 누르면 하위 메뉴가 열리고, 메뉴를 고르면 화면이 바뀝니다.
화면을 옮길 때마다 하단에 탭이 쌓이며, `Esc` 키로 전체 화면 목차가 열립니다.

## 검토 대상 화면

| 화면 ID | 화면명 |
|---|---|
| PCMS-SCR-ET-01-001 | 예비생 대시보드 (기획 미확정 — 디자인 스타일만) |
| PCMS-SCR-ET-02-012 | 예비생 등록·관리 |
| PCMS-SCR-ET-02-010 | 설명회 예약자 현황 |
| PCMS-SCR-ET-04-001 | 진학생 관리 |
| PCMS-SCR-ET-05-001 | 반편성 배치관리 |

공통 모듈 모달 4종(SMS 발송 · 상담이력 · 담당자 찾기 · MAP 성적표)은 각 화면의 버튼으로 열립니다.

참고 화면(검토 대상 아님): 예비생정보 · MAP종합정보 · 예약표 · 응시료 납부 현황 · 예비생 등록(유치부·예비초1) · 입학 등록관리 · 웰컴 SMS 발송

> 화면의 수치는 검토용 샘플 값입니다.
