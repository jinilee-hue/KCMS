## 3-1. GNB 메뉴 (1 · 2 · 3뎁스 정렬)

드롭다운 박스는 1뎁스 탭 박스와 **좌측 경계가 정확히 일치**합니다(`left = 탭의 boundingRect.left`, 반올림하지 않음).

```
1뎁스 탭 글자        ┃ 기준선
2뎁스 카테고리 글자   ┃ 같은 기준선
3뎁스 항목 점        ┃ 기준선 +3.2px  ← 점 중심이 2뎁스 첫 글자 중심(+5.2px)에 오도록
3뎁스 항목 글자      ┃ 점(4px) + 간격(6px) 만큼 들여쓰기
```

**점 위치 계산** — 2뎁스 카테고리 12px 한글 글리프 폭 ≈ 10.4px → 첫 글자 중심 +5.2px.
점 지름이 4px 이므로 왼쪽 여백은 `5.2 − 2 = 3.2px`.

```css
.dditem{padding-left:3.2px;}
```

> 점을 `position:absolute; left:-10px` 으로 바깥에 띄우는 방식은 쓰지 않습니다 —
> 점이 열 사이 여백(26px)을 파고들어 열 간격이 좌 16 / 우 26 으로 비대칭이 됩니다.

드롭다운 여백: 박스 `14px 18px`, 열 간격 `18px 26px`, 열 최소 폭 `118px`.

## 3-2. 레벨 필터 — 체크박스 트리 (.ctree)

진학생 관리(04-001)의 **현재 레벨 · 진학 레벨** 은 한 줄짜리 셀렉트가 아니라 **체크박스 트리**입니다.
레벨이 40종이라 한 줄 목록에서는 원하는 과정을 찾기 어렵기 때문입니다.

```
묶음   과정군 10개 (ECP · GT · MGT · S · MAG · LX · Honors · Leaders · Masters · Elites)
머리   검색 · 전체펼치기 · 전체해제
규칙   묶음 체크 = 하위 전체 · 일부 체크 = 중간 상태
       아무것도 안 고름 = 전부 고름 = 전체(제한 없음)
겉박스 커스텀 셀렉트와 같은 24px — 다른 것은 열렸을 때의 목록뿐
```

묶음 이름은 레벨명에서 숫자·공백 앞부분을 딴 것입니다(`ECP6m`→ECP, `LX A`→LX, `Honors 1`→Honors).

**현재 학급 · 진학 학급**(각 80종)도 같은 트리입니다 — 묶음은 과정군, 잎은 학급(`ECP6-A`)이고
오른쪽 대괄호 숫자는 **[배정 인원 / 정원 12]** 입니다. 묶음 행에는 그 합이 표시됩니다.
두 트리는 세는 칸이 달라 숫자도 다릅니다 — 현재 학급 `ECP [24/144]` · 진학 학급 `ECP [17/144]`.
장식용 숫자가 아니라 실제 배정 인원이라 그 반을 고르면 검색 결과 건수와 정확히 같습니다.

검색 필터 10종 중 **레벨 2 · 학급 2, 모두 네 칸이 체크박스 트리**입니다.

검색폼 레벨 두 칸의 자리는 **1행 끝 = 진학 레벨 · 2행 = 현재 레벨** 입니다(2026-08-27 요청).

## 6. 색 규칙

**브랜드**

```
--pb          #0066FF     기준색
--pb-light    #E8F0FF     틴트 배경
--pb-deeper   #003D99     가장 진한 단계
--gnb         #2C3E5A     상단 바
```

**지표 색 (그래프·진행바)** — 기준선이 있는 지표는 두 가지로만 가릅니다.

| | 그래프 (면적 넓음) | 글자·아이콘 (면적 좁음) |
|---|---|---|
| 기준 이상 | `#5E93EE` 톤다운 파랑 | `#0066FF` |
| 기준 미만(경고) | `#E58388` 톤다운 레드 | `#e5484d` |

기준값: **충원율 70%** / **가동률 30%** (화면에 "기준 N%" 로 표기)

> 면적이 넓은 그래프에 원색을 쓰면 촌스럽고, 작은 글자에 톤다운 색을 쓰면 뿌옇게 보입니다.

**차트 안 % 라벨** — 검정 `#1F2937` / 800, `%` 기호만 `0.68em`.
각 차트에서 **최고값 하나만** 원색(파랑 또는 레드)으로 강조합니다.

**토스트** — success / warning / danger / neutral 4색. 왼쪽 두꺼운 라인 금지, 배경은 의미색 투명도. **문구에 이모지 금지.**

**달력** — **오늘** `#0066FF` 원 채움 + 흰 글자 / **선택일** 파란 1px 링 + 파란 글자.
파란색은 `#0066FF` 한 가지만 쓰고, 둘의 구분은 색이 아니라 형태(채움 ↔ 링)로 합니다.
(이전에는 오늘 `#0066FF` 채움 / 선택 `#003D99` 남색 채움이라 달력마다 파랑이 두 가지로 보였습니다)

## 7. 하단 작업 탭 동작

- 메뉴에서 화면을 열면 탭이 **옆으로 쌓입니다**. 이미 열린 화면은 새 탭을 만들지 않고 그 탭을 활성화합니다.
- 탭이 넘치면 좌우 `‹ ›` 버튼이 나타납니다. (넘치지 않으면 숨김)
- 열린 목록은 체험판 셸이 보관하고 화면마다 내려줍니다 (`window.__PCMS_TABS`).

**좌우 이동 버튼 공통 규격**

| | GNB (어두운 바) | 작업 탭 (밝은 바) |
|---|---|---|
| 크기 | 26×26, 라운드 7px | 24×24, 라운드 6px |
| 배경 | `#fff` + 그림자 | `#fff` + 1px `#cfd7e3` |
| hover | `#E8F0FF` + `#0066FF` | `#E8F0FF` + `#0066FF` |

hover 시 **바 전체가 아니라 버튼 박스만** 바뀝니다.
