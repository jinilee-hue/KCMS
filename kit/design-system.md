
## 8. Kit 제작 방식 (2026-08-27)

Kit 의 `common.css` 는 **손으로 다시 쓰지 않습니다.** `build-css.py` 가 기준 화면의 CSS 에서
규칙을 추출해 만듭니다. 규격 문서를 보고 재구현하면 값이 미세하게 어긋나기 때문입니다.

```
기준 화면 02-012  →  id 로 한정된 조각만 제거  →  원본 순서 유지  →  common.css
대시보드 01-001   →  지표·차트 컴포넌트(kpi/stat/bar/chart/matrix)만 추가
반편성  05-001    →  커스텀 셀렉트(.csel)만 추가
_src/extras.css   →  화면에 없던 보강 컴포넌트(KCMS 톤으로 작성) 덧붙임
```

**추출 시 주의 (실제로 겪은 함정)**

| 함정 | 증상 | 대응 |
|---|---|---|
| 주석 안의 `#id` | 공통 규칙이 "화면 전용"으로 오인돼 누락 | 선택자와 주석을 분리해 판정 |
| 주석 안의 `{ }` | 주석 조각이 선택자로 튀어나와 이후 규칙이 통째로 무효화 | 파싱 전 주석을 자리표시자로 치환 |
| 콤마 목록 속 id | `.btn.danger,#rDeleteBtn{...}` 규칙 전체가 누락 | 콤마 조각 단위로 id 부분만 제거 |
| 순서 재정렬 | 뒤쪽 패치가 앞쪽을 덮는 구조가 깨짐 | 원본 순서 그대로 출력 |

**주의할 계약 두 가지**

1. 모달을 여는 클래스는 **`.open`** 입니다 (`.modal-ov.open{display:flex}`). `.on` 은 과거 코드용 별칭입니다.
2. 토스트는 **타입을 생략하면 neutral** 이고, 문구에 뚜렷한 단서가 있을 때만 success/warning/danger 로 올립니다.

## 11. 셀렉트 네 가지 (2026-08-27 확정)

박스 모양은 넷 다 같습니다 — 높이 24px · 라운드 3px · 오른쪽 v 화살표. **다른 것은 열렸을 때의 목록뿐**입니다.

| 종류 | 클래스 | 목록을 그리는 주체 | 언제 |
|---|---|---|---|
| **커스텀 (기본)** | `<select>` → `.csel` | Kit | 모든 셀렉트 — `initLayout()` 이 자동 변환 |
| 네이티브 | `data-nocsel` | 브라우저 | 예외 — 짧고 스타일이 상관없는 목록 |
| 트리(단일) | `.tsel` | Kit | 값에 계층이 있고 **하나만** 고를 때 (과정 → 레벨 → 반) |
| 트리(다중) | `.ctree` | Kit | 값에 계층이 있고 **여러 개**를 고를 때 (레벨 필터 등) |

**트리 셀렉트** — 중첩 `<ul><li data-v="값">` 을 읽어 만듭니다. 상위 노드는 펼침/접힘만 하고 잎 노드만 선택됩니다.
값은 숨은 `input[type=hidden]` 에 들어가고 `change` 가 발생하므로 폼 코드는 일반 select 와 동일하게 붙입니다.
`data-count` 로 우측에 참고 숫자(하위 개수 등)를 표시할 수 있습니다.

**체크박스 트리(.ctree)** — 여러 개를 한 번에 고르는 계층 목록입니다. 머리에 검색 · 전체펼치기 · 전체해제를 두고,
묶음(과정군)을 체크하면 하위가 전부 켜지고 일부만 켜지면 중간 상태로 표시됩니다.
**아무것도 고르지 않은 상태와 전부 고른 상태는 모두 "전체"(제한 없음)** 로 읽습니다 — 40종짜리 레벨 필터가 첫 사례입니다.
값은 숨은 `input` 에 쉼표로 들어가고 `change` 가 발생하며, `el.__ctree.values()` 는 선택 배열(전체면 `null`)을 돌려줍니다.
처음에는 묶음만 접힌 채 보여 목록이 열 줄을 넘지 않습니다.
잎에 `data-count="3/12"`(배정/정원 같은 참고 수치)를 주면 묶음 행에는 그 합계가 자동으로 표시됩니다 —
**표시용 숫자가 아니라 실제 값**이어야 합니다 — 진학생 관리에서는 그 반에 배정된 인원 수이고,
현재 학급 트리는 `curClass`, 진학 학급 트리는 `nextClass` 를 세므로 같은 반이라도 숫자가 다릅니다
(`ECP [24/144]` ↔ `ECP [17/144]`). 이 화면에서는 레벨 2칸 · 학급 2칸, **검색 필터 네 칸이 모두 이 트리**입니다.
