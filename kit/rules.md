# KCMS 입학관리 Kit — 규칙 · 계약

컴포넌트 가이드(`components.html`)는 **보이는 것**만 두고, 지켜야 할 규칙과 API 계약은 이 문서에 모읍니다.
관련 문서: `design-system.md`(구성·제작 방식) · `kcms-admissions.md`(AI 에이전트용 규약)

---

## 0. Kit 의 범위

**입학관리 GNB 3뎁스 메뉴 5페이지와 그 안에서 열리는 모달까지**입니다.

| 카테고리 | 화면 |
|---|---|
| 예비생 대시보드 | 예비생 대시보드 (ET-01-001) |
| 예비생 관리 | 예비생 등록·관리 (ET-02-012) · 설명회 예약자 현황 (ET-02-010) |
| 진학생 관리 | 진학생 관리 (ET-04-001) |
| 신학기 학급편성 | 반편성 배치관리 (ET-05-001) |

모달은 SMS 발송 · SMS 발송내역 · 학생메모 · 담당자 찾기 · MAP 성적표와
각 화면이 자체로 띄우는 팝업입니다.

**이 범위 밖 화면에서만 쓰는 컴포넌트는 Kit 에 싣지 않습니다.** 다른 메뉴(학생관리 등)나
메뉴에서 내린 화면의 것을 데모에 올리면, 쓰지 않는 규격을 표준으로 착각하게 됩니다.

## 1. Do / Don't

| 영역 | 이렇게 | 이러지 않기 |
|---|---|---|
| 색 | 토큰 변수만 사용 `var(--pb)` | hex 하드코딩 · 새 파랑 추가 |
| 지표 색 | 그래프는 톤다운, 글자는 원색 | 넓은 면적에 원색 · 작은 글자에 톤다운 |
| 차트 | 브랜드 파랑 농도로 구분 | 빨강·주황·초록 (기준 미달 경고만 예외) |
| 배지 | 굵기 500 · 용도별 클래스 | 굵기 700 · 아무 배지나 재사용 |
| 삭제 버튼 | 되돌릴 수 없는 동작만 빨강 | 행 삭제 · 탭 닫기에 빨강 |
| 토스트 | 배경색으로 상황 구분 · 순수 텍스트 | 좌측 액센트 바 · 이모지 |
| 탭 | 상위·하위는 밑줄, 토글은 채움 | 상·하위를 같은 모양으로 |
| 날짜 | 하이픈 `2026-08-27` | 점 `2026.08.27` |
| 타이포 | 8단계 안에서 선택 · 강조는 굵기로 | 새 크기 추가 · 본문 키워 강조 |
| 달력 | 오늘 채움 / 선택 링 · 파랑 한 가지 | 오늘·선택에 서로 다른 파랑 |

## 2. 컴포넌트별 금지 · 원칙

| 컴포넌트 | 규칙 |
|---|---|
| 타이포 | 크기 단계를 늘리지 않는다 (6단계 고정) |
| 간격 · 라운드 | 토큰에 없는 새 값을 만들지 않는다 |
| 그림자 | 카드 · 패널 · 표에 그림자 금지 — 구분은 1px 테두리 |
| 아이콘 | 채움(fill) 아이콘 금지 — 선 아이콘 `currentColor` |
| 탭 | 상위 · 하위 · 토글 **세 모양이 서로 달라야 한다** |
| 하위 탭 | 컨테이너 배경 금지 (알약 버튼만) |
| 토글(`.seg`) | 탭이 아니라 값 전환 · **버튼 사이 구분선 없음**(gap 0 · 활성 버튼만 파랑 채움 + 라운드 6px) |
| 배지 | 굵기 700 금지 (500 고정) |
| 폼 | 포커스 링 · 그림자 금지 — 테두리 색만 바뀐다 |
| 검색폼 칸선 | `.hascell` 클래스로 준다 — `td:has(.fselect)` 처럼 컨트롤 종류로 잡지 않는다 |
| 트리(다중) | 단일 선택에 쓰지 않는다 · 전부 체크 = 전체(제한 없음) |
| 트리 카운트 | 장식용 숫자 금지 — 실제 값만. 세는 칸이 다르면 숫자도 달라야 한다 |
| 날짜 · 달력 | 파랑 두 가지 금지 — 오늘은 채움, 선택은 링 |
| 모달 | 본문에 테두리 없음 (흰 박스) |

## 3. 컴포넌트별 상세 규칙

### 색 — 지표

기준선이 있는 지표(충원율 70% · 가동률 30%)는 **두 가지로만** 가릅니다.

| | 면적이 넓은 그래프 · 진행바 | 면적이 좁은 글자 · 아이콘 |
|---|---|---|
| 기준 이상 | `--chart-ok` 톤다운 파랑 | `--pb` 원색 |
| 기준 미만 | `--chart-low` 톤다운 레드 | `--danger` 원색 |

### 컴포넌트별 고정 글자 크기

16개 화면 전수 확인(2026-08-27)으로 아래 값이 **모든 화면에서 동일**합니다. 새로 만들 때도 이 값을 씁니다.

| 크기 | 굵기 | 쓰는 곳 |
|---|---|---|
| 13px | 700 | 모달 제목 · 섹션 제목 `.sectit` |
| 12px | 500 | 버튼 `.btn`(작은 버튼 포함) · 페이징 `.pgnum` `.pgnav` · 상위 탭 `.ptab` |
| 11.5px | 700 | 표 헤더 `th` · 세로형 표 라벨 · 필터 라벨 `.flabel` · 토글 `.seg` |
| 11.5px | 400 | 표 셀 `td` · 입력 `.finput` · 셀렉트 `.fselect` · 커스텀 셀렉트 `.csel-box` · 트리 `.ctree-box` |
| 11px | 400 | 섹션 제목 옆 보조 설명 `.hint` · 트리 카운트 |
| 10.5px | 500 | 배지 `.badge` · 상태 알약 `.statuspill` |

> 예외는 **예비생 대시보드(01-001)** 뿐입니다 — 지표 화면이라 제목 17px · 큰 수치 34px 등 자체 스케일을 씁니다.

### 타이포


- 크기 단계를 새로 만들지 않습니다 — 8단계 안에서 고릅니다.
- 강조는 **굵기**로 합니다. 본문 크기를 키워 강조하지 않습니다.
- 줄간격은 본문 1.5 · 설명문 1.7. 표 안은 줄간격 없이 셀 높이(24px)로 맞춥니다.
- 굵기 800 은 지표 수치만. 그 외 강조는 700 까지입니다.

### 여백 · 간격

```
섹션 제목      위 12px · 아래 8px
패널           안쪽 14px · 패널끼리 세로 12px
콘텐츠 기준선   좌우 73px (밴드는 화면 끝까지, 안쪽 여백 14px)
액션바 ↔ 표     6px          표 ↔ 페이징     8px
```

### 탭 — 어떤 걸 쓸지

| 상황 | 쓰는 것 |
|---|---|
| 내용 자체가 다른 화면으로 바뀐다 | 상위 탭 (밑줄) |
| 같은 화면에서 목록을 나눈다 | 하위 탭 (알약) |
| 값을 바꾸거나 조건을 켠다/끈다 | 토글 (붙은 박스) |

### 셀렉트 — 언제 무엇을

| 종류 | 언제 |
|---|---|
| **커스텀 셀렉트 (기본)** | 화면의 모든 `<select>` — `initLayout()` 이 자동으로 바꿉니다 |
| 체크박스 트리 `.ctree` | 값에 계층이 있고 여러 개를 고를 때 (현재 레벨 · 현재 학급) |

박스 모양은 둘 다 같습니다(24px · 라운드 3px · 오른쪽 v 화살표). 다른 건 열렸을 때의 목록뿐입니다.
목록은 박스 폭에 맞추고(최소 240px), 오른쪽 여유가 없으면 박스 오른쪽 끝 기준으로 펼칩니다.

**네이티브 `<select>` 는 5페이지에 하나도 없습니다**(실측) — 페이지당 개수까지 전부 커스텀으로 바뀝니다.
계층을 하나만 고르는 트리(`.tsel`)도 쓰는 곳이 없어 Kit 에서 내렸습니다.

비활성은 `select` 에 `disabled` 만 주면 됩니다 — 래퍼에 `.csel-disabled` 가 붙어
회색 배경이 되고 열리지 않습니다(진학생 관리에서 씁니다).

표 안 인라인 편집 셀렉트는 클래스가 `.csel.h22` 지만 **실제 높이는 24px** 입니다 —
2026-08-28 컨트롤 높이 통일이 덮어씁니다. 이름과 값이 어긋나 있으니 22px 로 읽지 마세요.

### 표 — 정렬

`th.sortable` 을 누르면 그 열로 정렬하고, 다시 누르면 방향이 바뀝니다.

화살표(`.tharrow`)는 정렬 가능한 열이면 **늘 보입니다** — hover 로 나타났다 사라지면
누를 수 있는 자리인지 알 수 없고, 자리도 흔들립니다.

| 상태 | 클래스 | 모양 |
|---|---|---|
| 기본 | `.tharrow` | ▾ · 진회색 `#2C3E5A` |
| 내림차순 | `.tharrow.on` | ▾ · 파랑 `--pb` |
| 오름차순 | `.tharrow.on.up` | ▾ 를 `rotate(180deg)` · 파랑 |

**글리프는 `▾` 하나뿐입니다.** 방향은 `.up` 의 회전으로 표현합니다 —
`▴`·`▲` 는 본문 폰트(Pretendard)에 없어 다른 폰트로 폴백되면서 `▾` 보다 크게 그려집니다.
정렬을 걸면 그 열 화살표만 커 보이던 원인이었습니다.

크기는 **16×16 박스 · `font-size:13px`** 로 목록·모달·불러오기 표가 모두 같습니다.
표마다 다른 클래스(`.sarrow`·`.sortArrow`)를 만들지 말고 `.tharrow` 하나를 씁니다.

### 표 — 스크롤 정책

**스크롤은 언제나 표를 감싼 `.tblwrap` 이 합니다.** 페이지(문서)는 스크롤하지 않습니다 —
앱 셸이 `100vh` 이고 `.content` 가 `overflow:hidden` 이라, 목록이 길어져도 늘어나는 것은 표 영역뿐입니다.
(실측: 진학생 관리 30행 목록 = 표 912px 가 458px wrap 안에서 스크롤, 문서 스크롤 없음)

| 경우 | 처리 |
|---|---|
| 세로 | 감싼 박스가 스크롤. **헤더(th)와 그 위 파란 선까지 고정**되고 `td` 만 움직인다 |
| 가로 | 같은 `.tblwrap` 이 담당 — 카드·모달이 가로로 늘어나지 않게 |
| 가로 · 세로 동시 | 한 컨테이너가 둘 다 처리하고, 헤더는 세로 스크롤에서만 고정 |

보드형(반편성)도 같은 규칙입니다.

| 뷰 | 스크롤 컨테이너 |
|---|---|
| 통합 배치표 | `.matwrap` 하나가 가로·세로 |
| 학생 리스트 | `.board` 하나가 가로·세로 (바깥 `.boardwrap` 은 스크롤하지 않음) |

**스크롤 컨테이너는 한 겹만 둡니다.** 겹치면 막대가 두 개 생깁니다 — 학생 리스트 뷰가 그랬습니다.
`overflow` 는 한 축만 `visible` 로 둘 수 없다는 점도 함께 기억해 두세요(`visible + auto` → 둘 다 `auto`).

막대 모양은 축마다 다릅니다(`overlay-scroll.js`).

| 축 | 막대 | 이유 |
|---|---|---|
| 세로 | 표 **안에 떠 있는** 6px 막대 (`rgba(44,62,90,.28)`) · 헤더 아래에서 시작 | 자리를 차지하지 않아 열 너비가 밀리지 않는다 |
| 가로 | 표 **아래 기본 막대** 8px — 숨기지 않는다 | 어디까지 밀렸는지 늘 보여야 하고, 아래는 가릴 내용이 없다 |

표가 아닌 영역(모달 본문·패널)에 같은 막대를 쓰려면 **`.pcms-ovscroll`** 을 붙입니다.
`.ovscroll` 은 SMS 발송 모달이 선점한 이름이라, 그대로 쓰면 그쪽 `pointer-events:none` 이
함께 걸려 표의 휠·클릭이 막힙니다.

크롬 함정 둘 — `::-webkit-scrollbar:vertical` / `:horizontal` 은 더 이상 적용되지 않습니다
(방향 없는 `::-webkit-scrollbar` 에서 `width` = 세로 폭, `height` = 가로 높이).
그리고 `scrollbar-width` 가 지정돼 있으면 `::-webkit-scrollbar` 규칙 전체가 무시됩니다.

행 수는 **페이징으로 끊습니다**(기본 30건) — 무한 스크롤은 쓰지 않습니다.
모달 안 표도 같은 규칙이고, 모달 본문이 아니라 `.tblwrap` 이 스크롤합니다.

### 배지

Kit 범위 5페이지와 그 모달에서 실제로 쓰는 배지는 **4가지**입니다(2026-08-29 실측, 모달을 연 상태 포함).
새 배지를 만들지 말고 이 안에서 고릅니다.

| 톤 | 값 | 쓰임 | 클래스 |
|---|---|---|---|
| 회색 채움 | `#EEF1F5` + `--txt-mut` | 남은 날짜(D-day) 등 눈에 띌 필요가 없는 값 | `.ddaybadge` |
| 파랑 틴트 | `--pb-light` + `--pb-dark` | 건수 · MAP 대상 | `.cntbadge` `.agebadge.mapin` |
| 레드 틴트 | `--danger-bg` + `--danger` | 남은 자리(TO) | `.tobadge.open` |
| 레드 채움 | `#E6483C` + 흰 | GNB 탭의 NEW | `.tabbadge` |

공통 규격은 **10.5px / 500 · 높이 16px · 라운드 999px** 입니다.

범위 밖 화면에는 흰 배경(`.badge.has`) · 파랑 채움(`.mapbadge.brand`) · 진회색 채움(`.qbadge`) ·
고르는 칩(`.tag2`) · 달력 칸 태그(`.rcal-cell .tag`)가 더 있지만, 5페이지에서 쓰지 않으므로 Kit 에 싣지 않습니다.

### 세로형 표 — 줄 높이

한 줄 칸은 **33px** 로 맞춥니다(패딩 대신 행 높이 + `vertical-align:middle`).
다만 **여러 줄 입력(textarea)이 든 칸은 예외** — 위아래 4px 패딩을 돌려주고 높이는 내용에 맡깁니다(행 68px).
패딩을 0 으로 두면 특이사항처럼 여러 줄이 들어가는 칸이 위아래로 붙어 보입니다.

### 폼 — 규격

컨트롤은 **어디서나 24px** 입니다 — 표 안 인라인 편집 · 페이징 · 탭 알약 · 기간 탭까지 한 값입니다(2026-08-28 통일).
높이가 다른 것은 성격이 다른 셋뿐입니다 — 토글 스위치 18px · 체크/라디오 14px · 토글(.seg) 안쪽 버튼 20px(24px 박스 안 1px 여백).

```
버튼 · 입력 · 셀렉트 · 트리 · 날짜 · 검색상자 · 세그먼트   24px
표 안 인라인 편집(셀렉트·입력) · 페이징 버튼 · 페이지 입력   24px
하위 탭(알약) · 기간 탭          24px
토글 스위치                    18px      체크 · 라디오   14px
라벨 .flabel  11.5 / 700 #2C3E5A · 필수 .req 빨간 별 · 도움말 .form-hint · 오류 .form-error
```

**기간 간편선택(1일 · 1주 · 15일 · 1달 · 전체)은 붙은 세그먼트가 아니라 떨어진 개별 버튼입니다**
— 4px 간격 · 24px · 라운드 3px · 테두리 1px · 글자 12px, 선택된 것만 파란 배경(2026-08-29 통일).
모달마다 `.qbtn` · `.shSeg button` · `.mcSeg button` 로 이름은 다르지만 모양은 하나입니다.

**표 상단 파란 라인은 1px 한 겹, 셀을 덮는 오버레이로 그립니다** — `::before` 를 좌우로 1px 씩
넘겨 깔아 th 세로 보더 끝을 덮습니다. 안쪽 그림자(`box-shadow: inset`)로 그리면 세로 보더가
라인 위로 1px 올라와 눈금처럼 보이고, 래퍼 `border-top` 과 함께 쓰면 2px 로 겹칩니다(2026-08-29 통일).

### 버튼

높이 **24px 한 가지** · 라운드 3px · 글자 12px/500 · **최소 폭 56px**(표 안 `.btn.sm` 제외).
`.btn.sm` 은 작은 버튼이 아니라 **좌우 여백만 좁힌 변형**입니다(패딩 10px→8px, 높이·글자는 같음).

버튼은 **세 가지**만 씁니다.

| 종류 | 쓰는 곳 |
|---|---|
| 기본 | `.btn`(주요) · `.btn.g`(보조) · `.btn.s`(시스템) · `.btn.danger`(되돌릴 수 없는 동작) |
| 아이콘 포함 | 글자 앞에 11px 선 아이콘 — 등록 · 수정 · 다운로드 |
| 아이콘 전용 | 단독 버튼은 **24px**(다른 컨트롤과 같은 높이) · 입력창 안에 붙는 `.ibtn` 만 **19×18px** (24px 입력 안에 들어가야 하므로) |

아이콘 전용 버튼을 본문에 단독으로 두지 않습니다(화면에 그런 사례가 없습니다).
달력 아이콘은 `<rect x="3" y="5" width="18" height="16" rx="2"/><path d="M3 9h18M8 3v4M16 3v4"/>` · stroke 1.8 · 11×11 고정입니다.
한 줄에 여러 개면 **주요 1개 + 보조 여러 개**로 두고, 주요 버튼을 가장 오른쪽에 둡니다.


**컨트롤 높이는 24px 하나입니다** — 버튼 · 입력 · 셀렉트 · 페이징 · 알약 탭 모두.

예외는 **다른 컨트롤에 딸린 아이콘**뿐입니다. 혼자 서는 버튼이 아니라 부속이라
같은 높이를 주면 오히려 어긋납니다.

| 아이콘 | 높이 | 어디에 |
|---|---|---|
| `.ibtn` | 18px | 24px 입력 필드 **안**의 달력·검색 아이콘 — 24px 로 올리면 필드를 넘칩니다 |
| `.bcic` | 20px | 브레드크럼 바(38px) 안의 즐겨찾기·새로고침·닫기 묶음 |

### 상태

- 포커스는 **테두리 색만** 파랑 — 링·그림자를 쓰지 않습니다(밀도 높은 표 화면에서 링은 시끄럽습니다).
- 비활성은 `opacity:.45` 또는 회색 배경 `#F0F2F5` + 회색 글자.
- 선택은 파랑 틴트 `--pb-light`, hover 는 그보다 옅은 `--pb-a08`.

### 날짜 필드 — 한 가지 폼

날짜 입력은 어디서나 같은 세 조각입니다.

```
[보이는 텍스트 입력 24px] + [숨은 input(type=date)] + [달력 버튼 .ibtn 19×18]
```

숨은 `input[type=date]` 는 브라우저 달력을 부르기 위한 것(1px, 눈에 보이지 않음)이고,
달력 버튼을 누르면 그 입력의 `showPicker()` 가 호출돼 화면 공통 달력 패널이 열립니다.
공통 모달들은 자체 이름(`.mcIwrap` · `.shIwrap` …)을 쓰고 있었는데, 2026-08-28 에 공통 클래스
(`.iwrap` · `.dateshadow` · `.ibtn`)를 함께 붙여 **한 규칙으로 잡을 수 있게** 했습니다.

### 날짜 · 달력

파랑은 `#0066FF` 한 가지만 씁니다. 오늘과 선택일의 구분은 색이 아니라 **형태**(채움 ↔ 링)입니다.
표기는 하이픈 `2026-08-27` — 점 표기는 쓰지 않습니다(`KCMS.date('20260827')`).

### 시간

`<input type="time">` 을 그대로 쓰고, `time-picker.js` 가 `showPicker()` 를 가로채
공통 패널(`.pcmstp`)을 띄웁니다. 브라우저 기본 시간 위젯은 페이지 CSS 로 모양을 바꿀 수 없어
화면과 따로 놀았습니다. 기본 시계 아이콘은 감춥니다.

패널은 날짜 피커와 같은 방침입니다 — 바깥선 없이 그림자, 라운드 3px, 고른 값만 파란 배경.
**오전 · 오후 → 시(01~12) → 분(5분 단위)** 순서이고, 취소 · 적용으로 닫습니다.

**키보드 직접 입력을 막지 않습니다.** 값은 `HH:MM`(24시간)으로 쓰고 `input`·`change` 를
발생시키므로, 섀도우 입력을 함께 쓰는 폼에서도 그대로 동기화됩니다.

### 모달

| 크기 | 값 | 쓰는 곳 |
|---|---|---|
| 안내 | `width:280px` → 실제 **320px**(`min-width`) | 짧은 알림 + [확인] |
| 입력 | `width:480px` | 메모·간단 등록 폼 |
| 기본 | `.modal-box` **640px** | 라벨-값 표가 들어가는 표준 폼 |
| 넓게 | `.modal-box.wide` **900px** | 검색줄 + 목록 표 |

헤더 40px · 본문은 흰 박스(테두리 없음) · 하단 버튼은 오른쪽 정렬(주요 버튼이 맨 오른쪽) · 드래그 이동 · `Esc`/오버레이 클릭으로 닫힘.
`.modal-box.sm` `.modal-box.lg` 같은 임의 규격은 쓰지 않습니다 — 실제 화면에 없는 값입니다.

공통 모달을 쓰려면 `styles/modal-overrides.css` 를 `common.css` **다음에** 불러야 합니다.
모달 스크립트가 자기 스타일을 함께 주입하는데, 화면에서는 그 위에 이 보정 규칙이 얹혀
표 헤더 톤·여백이 다른 팝업과 같아집니다(없으면 헤더 글자가 흰색으로 보입니다).

**공통 모달**은 화면마다 새로 만들지 않고 아래 스크립트를 불러 함수로 엽니다.

| 모달 | 파일 | 여는 함수 |
|---|---|---|
| 담당자 찾기 | `staff-pick-modal.js` | `openStaffPickModal({onApply})` |
| 상담이력 | `memo-modal.js` | `openMemoModal({studentNo, name, records, …})` |
| SMS 발송 | `sms-modal.js` | `openSmsModal({senderOptions, recipients, …})` |
| SMS 발송이력 | `sms-history-modal.js` | `openSmsHistoryModal({student, records})` |
| MAP 성적표 | `map-report-modal.js` | `openMapReportCard({studentName, subjects, …})` — 모달이 아니라 **새 창** |

### 토스트

배경은 의미색을 92% 불투명으로 깔고(color-mix) 글자·아이콘은 흰색. 왼쪽 액센트 바 없음, 문구에 이모지 없음. 최대 4개까지 쌓입니다.
타입을 생략하면 **neutral** 이고, 문구에 뚜렷한 단서가 있을 때만 올립니다.

| 문구 단서 | 타입 |
|---|---|
| 되었습니다 · 완료 · 성공 · 저장했 | success |
| 주세요 · 하세요 · 필수 · 확인해 | warning |
| 수 없 · 실패 · 오류 · 불가 | danger |
| 그 외 | neutral |

## 4. 접근성 · 키보드

| 항목 | 규칙 |
|---|---|
| 키보드 | `Esc` 모달 · 달력 · 드롭다운 닫기 · `Tab` 이동 · `Enter`/`Space` 커스텀 셀렉트 열기 |
| 포커스 | 모달을 열면 첫 입력으로 포커스가 가고, 닫으면 열었던 버튼으로 돌아온다 |
| 역할 | 모달 `role="dialog" aria-modal="true"` · 토스트 `role="status"`(오류·경고는 `alert`) · 도움말 `role="tooltip"` |
| 아이콘 버튼 | 글자가 없으면 `aria-label` 필수 — 닫기 · 이전 · 다음 · 새로고침 |
| 대비 | 본문 `#1F2937` 12.6:1 · 보조 `#5B6776` 6.4:1 · 파랑 위 흰 글자 4.6:1 |
| 모션 | `prefers-reduced-motion` 이면 토스트 · 차트 애니메이션을 끈다 |

## 5. 계약 (API · 마크업)

**불러오기**

```html
<link rel="stylesheet" href="styles/tokens.css">
<link rel="stylesheet" href="styles/common.css">
<script src="js/utils.js"></script>
<script src="js/layout.js"></script>
<script src="js/date-picker.js"></script>   <!-- 날짜 입력이 있으면 -->
<script src="js/modal-drag.js"></script>    <!-- 모달을 쓰면 -->
```

**셸 — GNB · 레일 · 작업 탭**

```js
initLayout({ menu: PCMS_GNB_MENU, current: '입학관리',
             badges: PCMS_GNB_TAB_BADGES,
             railItems: PCMS_LEFT_RAIL_ITEMS, railCurrent: 'HOME' });
```

`initLayout()` 안에서 `initCsel()` · `initTreeSelect()` · `initCTree()` · 모달 드래그가 함께 켜집니다.

**페이지네이션**

```js
KCMS.renderPaging('#paging', { page: 3, total: 1284, size: 30,
                               onPage: function(p){ /* 페이지 이동 */ } });
```

**트리 셀렉트 — 단일 선택**

```html
<span class="tsel" data-tree data-placeholder="학급 선택">
  <ul>
    <li data-label="ECP" data-count="12">ECP
      <ul><li data-v="ECP5-Bee">ECP5-Bee</li></ul>
    </li>
  </ul>
</span>
```

**트리 셀렉트 — 다중 선택(체크박스)**

```html
<span class="ctree" data-ctree data-all data-placeholder="전체">
  <ul>
    <li data-label="ECP"><ul><li>ECP5</li><li data-count="3/12">ECP6</li></ul></li>
  </ul>
</span>
```

```js
el.__ctree.values();               // 선택 배열 · 전체면 null
el.__ctree.setAll(); el.__ctree.reset();
```

값은 숨은 `input` 에 쉼표로 들어가고 `change` 가 발생합니다. 잎의 `data-count="3/12"` 는 [배정/정원] 같은 **실제 수치**이고, 묶음 행에는 그 합이 표시됩니다.

**토스트**

```js
KCMS.toast('저장되었습니다.', 'success');   // success · warning · danger · neutral
KCMS.toast('조회 결과가 12건입니다.');       // 타입 생략 → neutral
```

**모달**

```js
KCMS.openModal('myModal');    // .modal-ov 에 .open 을 붙인다
KCMS.closeModal('myModal');
KCMS.bindModals();            // 오버레이 클릭 · Esc · ✕ 로 닫히도록 일괄 연결
```
