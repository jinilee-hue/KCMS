색 팔레트

지표 색 — 기준선이 있는 지표(충원율 70% · 가동률 30%)는 두 가지로만 가릅니다. 면적이 넓은 그래프·진행바는 톤다운(--chart-ok/--chart-low), 면적이 좁은 글자·아이콘은 원색(--pb/--danger).

타이포

서체는 Pretendard(없으면 맑은 고딕)입니다. 업무 화면은 한 화면에 많은 정보를 담기 때문에 본문 기준이 11.5px 로 낮고, 크기 단계도 6개로 좁습니다. 단계를 늘리지 마세요.

지켜야 할 것
· 크기 단계를 새로 만들지 않습니다. 위 8단계 안에서 고릅니다.

· 줄간격은 본문 1.5, 설명문 1.7. 표 안은 줄간격 없이 셀 높이(24px)로 맞춥니다.

③ 토글 탭 — 예외 (.quickpill · .seg)

탭이 아니라 같은 목록을 거르는 스위치입니다. 화면 구조를 바꾸지 않고 내용만 바뀝니다.
알약형 .quickpill 은 목록 위 빠른 필터에, 붙은형 .seg 는 폼 안 2~3개 상태 전환에 씁니다.

어떤 걸 쓸지
· 내용 자체가 다른 화면으로 바뀐다 → 상위 탭
· 같은 화면 안에서 영역이 나뉜다 → 하위 탭
· 같은 목록을 조건으로 거른다 → 토글 탭
상위·하위는 밑줄형, 토글은 채움형으로 모양을 반드시 다르게 둡니다.

커스텀 셀렉트

과정 레벨

네이티브 select 의 목록은 브라우저가 그려서 라운드·정렬을 맞출 수 없습니다. 원본 select 는 그대로 두고 표시용 위젯을 씌워, 목록이 박스 바로 아래·같은 라운드로 열립니다. data-csel 만 붙이면 initLayout() 이 변환합니다.

<select data-csel><option>전체 과정</option></select>
<!-- initLayout() 이 자동 변환. 원본 select 가 남아 있어 value·change 는 그대로 -->

토스트

배경은 의미색을 92% 불투명으로 깔고(color-mix) 글자·아이콘은 흰색입니다. 왼쪽 두꺼운 액센트 바를 쓰지 않고, 문구에 이모지를 넣지 않습니다. 최대 4개까지 쌓입니다. 타입을 생략하면 기본은 neutral 이고, 문구에 뚜렷한 단서가 있을 때만 그쪽으로 추정합니다 — 되었습니다·완료·성공·저장했 → success, 주세요·하세요·필수·확인해 → warning, 수 없·실패·오류·불가 → danger. 어디에도 걸리지 않으면 neutral 입니다. 
KCMS.toast('저장되었습니다.', 'success');   // success · warning · danger · neutral
KCMS.toast('조회 결과가 12건입니다.');            // 타입 생략 → 기본 neutral
