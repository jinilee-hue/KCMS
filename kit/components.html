색

브랜드 파랑은 본문 강조, 네이비는 상단 바 — 역할을 분리합니다. 그래프는 톤다운 색을 따로 씁니다.

지표 색 규칙 — 기준선이 있는 지표(충원율 70% · 가동률 30%)는 두 가지로만 가릅니다.
그래프처럼 면적이 넓은 곳은 톤다운(--chart-ok / --chart-low), 글자·아이콘은 원색(--pb / --danger)을 씁니다. 면적이 넓은데 원색이면 촌스럽고, 작은 글자에 톤다운이면 뿌옇습니다.

토스트

왼쪽 두꺼운 액센트 바를 넣지 않고 배경색 자체로 상황을 구분합니다. 문구에 이모지를 넣지 않습니다 — 구분은 색과 제목이 합니다. 동시에 최대 3개까지 쌓입니다.

차트 (Chart.js 프리셋)

KCMS.setChartDefaults();                 // 폰트·막대 두께·점 크기 일괄 설정
const c = KCMS.getChartColors();         // 브랜드 파랑 1색을 투명도로만 나눈 팔레트
new Chart(el, { type:'bar', data:{ datasets:[{ backgroundColor:c[0] }] } });

// 기준선이 있는 지표는 두 색으로만
bar.backgroundColor = KCMS.ruleColor(pct, 70);   // 70% 이상 파랑 / 미만 경고 레드
차트에 시맨틱 색(빨강·주황·초록)을 쓰지 않습니다. 예외는 기준 미달 경고뿐입니다.
