POLY CAMPUS MANAGEMENT SYSTEM

KCMS 입학관리 Kit

PCMS 입학관리 화면에서 확정된 규격을 그대로 옮긴 디자인 Kit 입니다. 빌드 도구·패키지 설치 없이 파일 4개만 불러오면 같은 화면이 나옵니다. 표·모달·토스트·GNB·작업 탭까지 업무 화면에 필요한 컴포넌트가 모두 들어 있습니다.

Kit 내려받기 (.zip) 컴포넌트 가이드 보기 입학관리 체험판

패키지 구성

화면에서 추출한 CSS + 유틸리티 — 컴포넌트 67개 실측 대조 완료

kcms-admissions.md
AI Agent 프롬프트

Cursor · VS Code · Claude Code 등 개발 Agent에 그대로 붙여넣는 UI 규약입니다. 규칙 설명 없이 바로 개발을 시작합니다.

styles/tokens.css
디자인 토큰

색·간격·타이포·컴포넌트 높이를 CSS 변수로 정의합니다. 값 하드코딩을 막는 단일 출처입니다.

styles/common.css
컴포넌트 스타일

실제 화면(PCMS-SCR-ET-02-012)의 CSS 에서 컴포넌트 규칙 1,300여 개를 원본 순서 그대로 추출했습니다. 대시보드의 지표·차트 컴포넌트와 커스텀 셀렉트도 함께 담았습니다. 손으로 다시 쓰지 않았기 때문에 화면과 결과가 어긋나지 않습니다.

js/utils.js
유틸리티

날짜·숫자·전화 포맷, 개인정보 마스킹, 4색 토스트, 모달 제어, Chart.js 프리셋이 들어 있습니다.

js/layout.js
레이아웃 엔진

GNB 3뎁스 메뉴, 좌측 레일, 하단 작업 탭, 셀렉트 폭 자동 계산, 모달 드래그를 initLayout() 한 줄로 초기화합니다.

js/date-picker.js
날짜 선택기

공용 달력. 오늘 = 파란 원 채움, 선택일 = 파란 테두리 링. 실제 화면 구현 그대로입니다.

js/modal-drag.js
모달 드래그

모달 헤더를 잡아 옮기는 동작. 화면 밖으로 나가지 않도록 위치를 보정합니다.

js/menu.sample.js
메뉴 샘플 데이터

GNB 1뎁스 11개 · 하위 106개 항목과 좌측 레일 13개. 실제 화면 구조 그대로라 항목만 갈아끼우면 됩니다.

공통 모달 5종 (js/)
화면이 함께 쓰는 모달

staff-pick-modal.js(담당자 찾기) · memo-modal.js(상담이력) · sms-modal.js(SMS 발송) · sms-history-modal.js(발송이력) · map-report-modal.js(MAP 성적표 — 새 창). 체험판 화면이 쓰는 파일 그대로라 컴포넌트 가이드에서도 실제 모달이 열립니다.

build-css.py
CSS 추출 스크립트

화면이 바뀌면 이 스크립트를 다시 돌려 common.css 를 갱신합니다. Kit 을 손으로 고치지 않습니다.

design-system.md
디자인 시스템 문서

색 스케일, 컴포넌트 스펙, 모달 인벤토리(44종), 반응형 브레이크포인트, 의도된 예외까지 담은 레퍼런스입니다.

rules.md
규칙 · 계약

Do/Don’t, 컴포넌트별 금지 사항, 접근성·키보드, 불러오기와 API 계약. 가이드 화면에는 컴포넌트만 두고 규칙은 이 문서에 모았습니다.

주요 특징

업무 화면의 밀도에 맞춰 설계했습니다

업무 화면 밀도 기준

표 헤더 33px, 버튼·입력 24px, 본문 11.5px. 한 화면에 많은 정보를 담는 업무 시스템 기준으로 잡힌 스케일입니다.

역할이 분리된 2색

상단 GNB는 네이비, 본문 강조는 Poly Blue. 화면 어디를 보고 있는지와 무엇을 눌러야 하는지가 색으로 갈립니다.

기준선이 있는 지표 색

충원율 70% · 가동률 30% 같은 기준을 넘었는지를 두 색으로만 표시합니다. 면적에 따라 톤다운/원색을 나눠 씁니다.

쌓이는 작업 탭

메뉴에서 화면을 열면 하단에 탭이 쌓이고, 넘치면 좌우 이동 버튼이 나타납니다. KCMS 사용 흐름 그대로입니다.

44종 모달 규격

공통 26종 · 화면 전용 18종을 한 셸(.modal-box)로 통일했습니다. 드래그 이동과 Esc 닫기가 기본입니다.

화면에서 추출한 CSS

규격을 문서만 보고 다시 구현하지 않습니다. 실제 화면의 CSS 를 그대로 옮겨 왔고, 컴포넌트 67개를 실측 대조해 값이 모두 같은 것을 확인했습니다.

Vanilla JS · 빌드 불필요

Node·번들러 없이 브라우저에서 바로 실행됩니다. 차트가 필요하면 Chart.js CDN 한 줄만 추가합니다.
