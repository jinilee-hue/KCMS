# KCMS 입학관리 UI 규약 (AI Agent 프롬프트)

> Cursor · VS Code · Claude Code 등 개발 Agent에 그대로 붙여넣어 쓰는 규약입니다.
> 이 규약을 따르면 KCMS 입학관리 화면과 동일한 결과가 나옵니다.

## 0. 전제

- **빌드 없음.** Vanilla HTML/CSS/JS. 번들러·Node 설치 불필요.
- 로드 순서: `styles/tokens.css` → `styles/common.css` → `js/utils.js` → `js/layout.js`
- 색·크기는 **하드코딩 금지.** 반드시 `tokens.css` 의 CSS 변수를 쓴다.
- 라이트 모드 전용. 다크 모드는 지원하지 않는다.

## 1. 색

| 용도 | 변수 |
|---|---|
| 본문 강조 (링크·활성·포커스) | `--pb` `#0066FF` |
| 틴트 배경 | `--pb-light` `#E8F0FF` |
| 상단 GNB | `--gnb` `#2C3E5A` (본문 강조색과 역할 분리) |
| 표 헤더 / 2단 그룹 헤더 | `--tbl-head` `#F4F7FD` / `--tbl-head-grp` `#EAF1FB` |
| 경고 / 위험 | `--warn` `#F97316` / `--danger` `#E5484D` |
| 그래프 기준 이상 / 미만 | `--chart-ok` `#5E93EE` / `--chart-low` `#E58388` |

**지표 색 규칙** — 기준선이 있는 지표(충원율 70%, 가동률 30%)는 두 가지로만 가른다.
- 면적이 넓은 **그래프·진행바** → 톤다운 (`--chart-ok` / `--chart-low`)
- 면적이 좁은 **글자·아이콘** → 원색 (`--pb` / `--danger`)

**차트에 시맨틱 색 금지.** 빨강·주황·초록은 배지·텍스트 전용이며, 차트에서는 기준 미달 경고에만 허용한다.

## 2. 크기

```
상단 GNB 64 · 좌측 레일 58 · 히스토리 네비 30 · 하단 작업 탭 30
버튼 24 (작게 22) · 입력 24 · 표 헤더 33 · 모달 헤더 40
패널 안쪽 여백 14 · 표 셀 좌우 8
```

타이포: 섹션 제목 13/700 · 탭 12.5/700 · 본문 11.5 · 배지 11/500

## 3. 컴포넌트 규칙

- **버튼** `.btn`(주요) / `.btn.g`(보조) / `.btn.s`(시스템) / `.btn.danger`(파괴적 동작만)
  일상적인 삭제·닫기 버튼에 **빨강을 쓰지 않는다** — 중립 톤(`#D7DDE6` hover).
- **배지** 굵기 **500** 고정(700 금지). 용도가 정해진 배지는 그 용도로만 쓴다 —
  `agebadge`(연령·MAP 대상) · `to-badge`(입학 시기) · `ddaybadge`(잔여일) · `mapbadge`(MAP 건수) ·
  `cntbadge`(개수) · `statuspill`(상태) · `typebadge`(구분). 그 외 일반 표시는 `.badge`.
- **표 — 두 형식만 쓴다.**
  · **가로형(목록)** `.tblwrap > table.grid` — 헤더 33px 고정(sticky) · 셀 24px · 짝수 행 줄무늬 · 선택 행 `.sel`
  · **세로형(상세)** `table.infotbl` — 라벨 `th` 92px `#F4F7FD` 가운데 정렬, 한 행에 라벨-값 2쌍
  · 검색 조건은 `table.fbox` (`.flabel` + `.hascell`, 셀 33px, 상단 파란 1px 선)
  숫자 칸 `.num`(우측 정렬 + 등폭), 2단 헤더 `.grp`.
- **탭** 상위는 밑줄형 `.ptab`, 하위 필터는 알약형 `.quickpill`. **토글 스위치형 금지.**
- **모달** `.modal-ov > .modal-box > (.modal-hd + .modal-body + .modal-foot)`.
  **여는 클래스는 `.open`** (`.modal-ov.open{display:flex}`). 헤더 드래그로 이동, Esc·오버레이 클릭으로 닫힘.
  `KCMS.openModal(id)` / `closeModal(id)` / `bindModals()`.
- **토스트** `KCMS.toast(msg, type)` — `success` · `warning` · `danger` · `neutral`.
  **타입을 생략하면 기본은 neutral**, 문구에 뚜렷한 단서가 있을 때만 추정해서 올린다
  (`되었습니다·완료` → success / `주세요·필수·확인해` → warning / `수 없·실패·오류` → danger).
  배경은 의미색 **70% 불투명**(color-mix) + 흰 글자. 최대 4개 스택.
  왼쪽 두꺼운 액센트 바 금지. **문구에 이모지 금지.** 최대 3개까지 쌓인다.
- **달력** 오늘 = 파란 원 채움 + 흰 글자 / 선택일 = 파란 테두리 링. 파랑은 `#0066FF` 한 가지만.
- **% 표기** 숫자는 800 굵기, `%` 기호만 `0.68em`(`<span class="pcts">%</span>`).
  차트에서는 **최고값 하나만** 원색으로 강조한다.

## 4. GNB 3뎁스 정렬

1뎁스 탭 글자 · 2뎁스 카테고리 · 3뎁스 항목 점이 **같은 세로선**에서 시작한다.
3뎁스 점은 2뎁스 첫 글자 가운데(+5.2px)에 중심을 맞추므로 `padding-left:3.2px`.

> 점을 `position:absolute; left:-10px` 로 바깥에 띄우지 말 것 — 열 사이 여백(26px)을 파고들어
> 열 간격이 좌 16 / 우 26 으로 비대칭이 된다.

## 4-1. 폼 · 셀렉트 · 페이지네이션

- 입력·셀렉트·날짜 필드 **높이 24px**, 포커스는 **테두리 색만** 파랑(링·그림자 없음).
- 날짜 필드는 `.iwrap` 안에 [텍스트 입력 + 숨은 `input[type=date]` + 달력 버튼] 구조.
- 셀렉트는 네 가지: 기본 `.fselect`(브라우저가 목록을 그림) · `data-csel`(목록이 길거나 잘리면 안 될 때) ·
  `.tsel`(계층 + 하나 선택) · `.ctree`(계층 + 여러 개 선택). **박스 모양은 넷 다 동일**하고 목록만 다르다.
- `.ctree` 는 검색 + 전체펼치기/전체해제 + 체크박스 트리다. 묶음 체크 = 하위 전체, 일부 체크 = 중간 상태,
  **아무것도 안 고름 = 전부 고름 = 전체(제한 없음)**. 값은 `el.__ctree.values()` (전체면 `null`).
- 페이지네이션은 `KCMS.renderPaging(el, {page, total, size, onPage})` —
  `« ‹ 번호 › »` · 페이지 직접 입력 · 새로고침 · 페이지당 개수 · 총 건수가 한 줄에 들어간다.

## 5. 하단 작업 탭

메뉴에서 화면을 열면 탭이 **옆으로 쌓인다.** 이미 열린 화면은 새 탭을 만들지 않고 활성화한다.
탭이 넘치면 좌우 `‹ ›` 버튼이 나타난다(넘치지 않으면 숨김). 버튼 hover 시 **바 전체가 아니라 버튼 박스만** 바뀐다.

## 6. 반응형

| 브레이크포인트 | 변화 |
|---|---|
| 1300px 이하 | 지표·차트 영역 1열 |
| 1100px 이하 | 검색 필터 줄바꿈 허용 |
| 1000px 이하 | 좌측 레일 58 → 50px |

어느 폭에서도 **페이지 가로 스크롤이 생기면 안 된다.** 넓은 표는 자체 컨테이너에서 스크롤한다.

## 7. 하지 말 것

- 토스트 문구에 이모지
- 배지 굵기 700
- 일상 동작 버튼에 빨강
- 하위 탭에 토글 스위치
